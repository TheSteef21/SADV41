⚡ Protocolo de Despliegue y Estado del Proyecto

Documentación oficial de los pasos para alojar la interfaz en GitHub Pages y el estado de conexión con la API de USGS.

Fase 1: Preparación y Subida a GitHub

1. Creación de Cuenta en GitHub

Si aún no lo has hecho, dirígete a github.com y regístrate. Solo necesitas un correo electrónico, un nombre de usuario (como TheSteef21) y una contraseña. Completa la verificación por correo.

2. Crear un Nuevo Repositorio

  • Inicia sesión y haz clic en el botón verde "New" (Nuevo repositorio).
  • Nómbralo algo representativo, por ejemplo: visor-landsat-usgs.
  • Asegúrate de marcarlo como "Public" (Público) para poder usar GitHub Pages gratis.
  • Haz clic en "Create repository".

3. Subir tus Archivos HTML

  • En la página de tu nuevo repositorio, haz clic en "uploading an existing file".
  • Arrastra o selecciona el archivo github.html (o tu index.html final) que creamos en Termux.
  • Escribe un mensaje de "Commit" (ej. "Versión inicial del dashboard") y presiona "Commit changes".

4. Activar GitHub Pages (Hosting Gratuito)

  • Ve a la pestaña "Settings" (Configuración) de tu repositorio.
  • En el menú lateral izquierdo, haz clic en "Pages".
  • Bajo "Source", selecciona la rama "main" y haz clic en "Save".
  • En un par de minutos, GitHub te dará un enlace en vivo (ej. https://thesteef21.github.io/visor-landsat-usgs) donde tu web estará pública para todo el mundo.

Fase 2: El Bloqueo M2M y la Espera de USGS

Estado Actual: Pendiente (Pending)

Hasta este punto, hemos configurado con éxito un servidor local en Termux (Flask), instalado la librería de Python usgs y establecido la conexión visual mediante la Fetch API de JavaScript.

Sin embargo, el hito final requiere la descarga de metadatos e imágenes satelitales (Landsat 8/9). Al intentar ejecutar comandos como download-options, nos topamos con un Error 403 (Forbidden).

¿Qué falta? Hemos enviado formalmente la solicitud de rol "Machine to Machine" (M2M) en el portal ERS del USGS. Este proceso de revisión es manual por parte del gobierno estadounidense y suele tardar un promedio de 1 a 3 días hábiles. Una vez que el estado cambie a "Approved", la API liberará el acceso y nuestro código JavaScript podrá consumir y renderizar las imágenes satelitales reales en este mismo panel.
